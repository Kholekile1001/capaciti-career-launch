# CAPACITI WorkSmart AI

An AI-powered career assistance platform built for South African youth, helping them unlock their potential through smarter job search, CV building, interview preparation, and skills assessment.

**Live URL:** [https://capaciti-career-launch.lovable.app](https://capaciti-career-launch.lovable.app)

---

## About

CAPACITI WorkSmart AI provides young job seekers with a modern, responsive dashboard and AI-guided tools to improve their employability. The platform features a dark blue and white visual identity aligned with the CAPACITI brand.

## Features

- **Dashboard** — Overview of jobs applied, interviews scheduled, skills completed, and profile score.
- **CV Builder** — Editable form with live preview to build and refine a professional CV.
- **Job Search** — Filterable job listings with detailed job cards.
- **Interview Prep** — AI-guided interview preparation resources and practice prompts.
- **Skills Assessment** — Tools to evaluate and track skill development.
- **AI Chatbot** — Floating assistant in the bottom-right corner for career guidance.
- **Responsive Design** — Works on desktop, tablet, and mobile devices.

## Tech Stack

- [TanStack Start](https://tanstack.com/start) — Full-stack React framework
- [React 19](https://react.dev) — UI library
- [TypeScript](https://www.typescriptlang.org) — Type-safe development
- [Tailwind CSS v4](https://tailwindcss.com) — Styling
- [Lovable](https://lovable.dev) — AI-assisted development and deployment

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm, yarn, pnpm, or bun

### Install dependencies

```sh
npm install
```

### Run the development server

```sh
npm run dev
```

The app will be available at `http://localhost:8080`.

### Build for production

```sh
npm run build
```
